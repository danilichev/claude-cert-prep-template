## Scenarios

The official guide lists no production scenarios. The list below is derived from the guide's competency list (section 2) and the settings of its three sample questions (section 8). It is a drill aid, not an official list.

- Overnight high-volume document processing pipeline (batch vs realtime, cost)
- User-facing agent that reads untrusted web content (summarizer / research agent)
- Shared internal REST service exposed to several Claude apps (tools, MCP server)
- Production Claude application integrated into an existing codebase (API, SDKs, streaming, errors, multi-format input)
- Agent or workflow built with the Claude Agent SDK or a custom agent loop
- Team using Claude Code for codebase modernization (CLAUDE.md, settings.json, Skills, plugins, hooks)
